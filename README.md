# SyncDesk — ซิงก์คลิปบอร์ด ไฟล์ และรีโมตระหว่างคอมกับมือถือ

## ส่วนประกอบ
| ไฟล์ | หน้าที่ |
|---|---|
| `server.js` | เซิร์ฟเวอร์กลาง สร้างห้อง, QR, ซิงก์แบบเรียลไทม์, อัปโหลด/ดาวน์โหลดไฟล์ |
| `public/index.html` | หน้าเว็บสำหรับคอม (Chrome / Edge / Chromebook) และ iPhone / Android |
| `helper/start-helper.bat` | ดับเบิลคลิกบน Windows เพื่อเปิดตัวช่วยซิงก์คลิปบอร์ดอัตโนมัติ |
| `helper/win-helper.js` | ตัวช่วย Windows: คัดลอกบนคอม → ขึ้นบนมือถือและกลับกัน, รับคำสั่งรีโมตลูกศร/Space |
| `render.yaml` | ตั้งค่า deploy ขึ้น Render แบบคลิกเดียว |

## 1) ทดสอบบนเครื่องตัวเอง
ต้องมี Node.js 18 ขึ้นไป
```
npm install
npm start
```
เปิด http://localhost:3000 แล้วกด "สร้างห้องใหม่"

> ถ้าจะให้ iPhone สแกนได้ ต้องเข้าผ่าน HTTPS ซึ่ง localhost ใช้ไม่ได้กับกล้องมือถือ ให้ deploy ตามข้อ 2

## 2) Deploy ขึ้น Render (มี HTTPS ให้อัตโนมัติ)
1. สร้าง repo บน GitHub แล้วอัปโหลดโฟลเดอร์นี้ทั้งหมด
2. เข้า https://render.com → New → Blueprint → เลือก repo นี้
3. รอ build เสร็จ จะได้ URL แบบ `https://syncdesk-xxxx.onrender.com`

หมายเหตุ: แผน Free ของ Render จะหลับเมื่อไม่มีการใช้งาน และไฟล์ที่อัปโหลดจะหายเมื่อ restart ถ้าใช้งานจริงจังแนะนำแผนแบบเสียเงิน

## 3) เชื่อม iPhone / Android / Chromebook
1. บนคอม เปิด URL ของเซิร์ฟเวอร์ แล้วกด "สร้างห้องใหม่"
2. ไปที่แท็บ QR แล้วสแกนด้วยกล้อง iPhone หรือ Android
3. หน้าเว็บจะเปิดและเข้าห้องเดียวกันอัตโนมัติ
4. บน iPhone: กด Share → "เพิ่มไปยังหน้าจอโฮม" เพื่อใช้แบบเต็มจอ

## 4) เปิดตัวช่วย Windows (ซิงก์คลิปบอร์ดอัตโนมัติ)
1. ติดตั้ง Node.js จาก https://nodejs.org (เลือก LTS)
2. ดับเบิลคลิก `helper/start-helper.bat`
3. วาง URL, Room ID และ Secret ที่เห็นในหน้าเว็บ (ดูได้จากลิงก์ QR ที่แท็บ QR: ค่า `r=` คือ Room และ `k=` คือ Secret)
4. เมื่อขึ้นว่า "เชื่อมต่อแล้ว" คัดลอกบน Windows แล้วข้อความจะขึ้นบนมือถือทันที

## ข้อจำกัดที่ควรรู้
- **iPhone:** เว็บอ่านคลิปบอร์ดอัตโนมัติไม่ได้ ต้องแตะ "วางจากคลิปบอร์ด" ทุกครั้ง และรับแจ้งเตือนเมื่อแอปอยู่เบื้องหลังไม่ได้
- **Chromebook / Chrome:** ใช้หน้าเว็บได้เต็มที่ แต่ตัวช่วยอัตโนมัติรองรับเฉพาะ Windows
- **รีโมต:** ลูกศรและ Space ส่งไปที่ตัวช่วย Windows ได้ ปุ่มเสียงต้องใช้ตัวช่วยเพิ่มเติม (ยังไม่รวมในเวอร์ชันนี้)
- **ความปลอดภัย:** ใครมี Room ID และ Secret จะเข้าห้องได้ อย่าส่ง QR ให้คนที่ไม่รู้จัก ถ้าหลุดให้สร้างห้องใหม่

## เพิ่มเติมที่ควรทำต่อ
- เพิ่มปุ่ม "ออกจากทุกเครื่อง" เพื่อเปลี่ยน Secret ของห้อง
- เพิ่มไอคอนแอป (ไฟล์ PNG ขนาด 192 และ 512) ในโฟลเดอร์ public
- เข้ารหัสข้อความที่ส่งระหว่างเครื่องแบบ end-to-end
